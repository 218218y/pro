# Layering completion audit

This file is intentionally compact. It keeps only current decomposition guard facts that tests assert and future refactors need. Historical stage-by-stage logs were removed.

It rejects unclassified ESM source, unapproved non-literal dynamic imports, `require()`, and TypeScript import-equals, while path-segment facade matching and a decrease-only proposal ratchet prevent prefix bypasses and automatic budget growth. Exact migration budgets may exempt one reviewed statement only when its file, target, import kind, symbols, canonical companion owner, removed legacy target, owner, review date, and removal condition all match; drift, disappearance, duplicate statements, or restoration of the legacy import fail closed, and the base edge ceiling remains unchanged.
